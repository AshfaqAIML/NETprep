# MASTER PROMPT — UGC NET COMPUTER SCIENCE & APPLICATIONS COMPLETE PYQ RESEARCH, EXTRACTION, VERIFICATION & IMPORT SYSTEM

The UGC NET preparation platform already contains a PYQ/question-bank system.

Your task now is to transform it into a **comprehensive, verified, structured historical database of UGC NET Computer Science & Applications previous-year questions**.

The objective is NOT merely to collect PDF files.

The objective is:

> Find as many genuine UGC NET Computer Science & Applications (Subject Code 087) examination papers and reliable answer keys as can be located, extract the individual questions, verify them, normalize them into the existing question-bank architecture, and organize them by year, exam cycle, paper/session, unit, topic, difficulty, and question type.

The final system should allow a student to explore:

**All PYQs → Year → Exam Cycle → Paper → Unit → Topic → Question**

and also:

**Topic → All Questions Ever Asked**

---

# 1. CRITICAL RESEARCH REQUIREMENT

Perform actual internet research.

Do NOT rely solely on:

* model memory
* already existing seed data
* one website
* one PDF collection
* one coaching website
* one search result

Search broadly and systematically.

Prioritize authoritative sources.

Use official sources wherever available, especially:

* UGC
* NTA
* official UGC-NET archives
* official examination notices
* official final answer keys
* official question-paper/recorded-response materials where publicly available

The official UGC-NET archive contains historical examination material, and older UGC pages expose previous-question-paper collections. Recent NTA material also contains question-paper/response and final-answer-key information.

Use reputable secondary sources only to fill gaps.

Never treat an unofficial source as authoritative merely because it appears high in search results.
